  1. 1Narrator caption. The interpreter for zero-Raft visitors: "Node 3 went down. The others will notice when heartbeats stop." Sourced from event-log deltas carrying narratorLine; never jargon.
  2. 2Seed field. Editable hex; Enter reloads the run deterministically. Share copies a URL encoding seed + every injected fault.
  3. 3Cluster stage. Role halo (leader amber + crown, follower steel, candidate violet, dead hatched + tilted), term number, commit arc. Click a node: Kill / Restart / Slow clock. The pulsing "Try: kill the leader" hint chip anchors to the leader on first visit.
  4. 4Log wall — the signature. One strip per node, one cell per entry tinted by term, green commit watermark. Diverges under partition, visibly reconciles on heal.
  5. 5Event log. Protocol truth for the curious; newest at bottom; filters: Elections · Appends · Client ops · Faults.
  6. 6Transport. Pause/play, single-step, speed 0.25–16×; scrubbing re-runs the deterministic sim to that instant. Keyboard: space, ., ←/→.
  7. 7Fault controls. Outcome-named, sentence case. Split network uses a 2/3 preset; long-press opens the group editor. Faults injected while paused land at the paused instant.
